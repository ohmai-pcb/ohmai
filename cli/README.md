# ohmai (CLI)

Command-line part of [OhmAI](../README.md). Install from a checkout:

```bash
pip install -e "cli[dev]"     # from the repo root
ohmai --help
```

Subcommands: `new`, `status`, `check <phase|check|current|all>`, `release`, `skill`.
See `docs/ARCHITECTURE.md` for what each check does.
